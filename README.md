# Строим всё! — сайт

Одностраничный сайт для компании **Строим всё!** (ООО «Строительная компания-2000») —
окна, остекление и отделка балконов, беседки, бани, дачи и коттеджи, ремонт помещений
(ТЦ «Палитра», проспект Мира, 49а, Набережные Челны).

- Данные: карточка [2ГИС](https://2gis.ru/nabchelny/firm/70000001054278774) — 4,7 ★,
  15 оценок, 56 фото, контакты, рубрики, оплата
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01/02/03

## Особенности этой карточки

- Открытого прайса в 2ГИС нет (вкладка «Цены» пустая), поэтому блок «Услуги» сделан
  карточками без цен — «цена по объекту»
- Фото работ взяты: 2 фирменных фото из галереи 2ГИС + 1 фото из отзывов
- Отзывы взяты через публичный API отзывов 2ГИС (полные тексты, оценки, даты)
- Адрес опубликован полностью: ТЦ «Палитра», пр. Мира, 49а, 26 офис, 4 этаж, 423809
- Режим: круглосуточно; оплата: наличные, через банк, перевод с карты
- Один отзыв на 1 звезду («.............») — на сайт не вынесен

## Локальный запуск

    python -m http.server 8000

и открыть http://localhost:8000

## Структура

    index.html   — вся страница
    css/style.css
    js/main.js
    img/         — фото работ из 2ГИС
